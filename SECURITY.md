# Security and Disclosure Notice

This repository is a sanitized portfolio case study and does not contain the private implementation used in the original professional environment.

Do not add production or employer-specific material to this repository, including:

- credentials or secrets
- certificates or private keys
- real network addresses or routes
- internal hostnames or domains
- customer or employer identifiers
- production PLC tag/register exports
- proprietary source code
- internal deployment scripts
- screenshots containing confidential information
- original private Git history

Any future example data committed here should be synthetic and independently created for demonstration purposes.
